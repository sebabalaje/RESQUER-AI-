# RESQUER AI roadmap

## Phase 1 — Working demo
- [x] FastAPI backend
- [x] TF-IDF + Logistic Regression toy baseline
- [x] Sentiment and interpretable lexical features
- [x] Consent confirmation gate
- [x] API tests

## Phase 2 — Research-grade evaluation
- [ ] Select a lawful, ethically governed, appropriately licensed dataset
- [ ] Define labels with qualified domain experts
- [ ] Split data by author/person to reduce leakage
- [ ] Report precision, recall, F1, calibration, and subgroup errors
- [ ] Compare a transformer model (e.g. BERT) against the baseline

## Phase 3 — Human-centered product
- [ ] React dashboard with clear uncertainty and explanations
- [ ] Data minimization and retention controls
- [ ] Opt-in resource suggestions and human review workflow
- [ ] Security, accessibility, and privacy review

Do not deploy for real-world monitoring or intervention before relevant research, legal, safety, and clinical review.
